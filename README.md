# JRAFT - Joes custom minecraft

Repository containing the Minecraft instance used for this modpack.

This modpack is a curated Fabric setup for Minecraft 1.21.11, focused on performance, visual enhancements, and immersive gameplay. It includes optimization mods like Lithium, Sodium, and C2ME, sound and visual immersion via AmbientEnvironment, AmbientSounds, PresenceFootsteps, Voxy, and Iris shaders, plus utility and gameplay mods such as Chisels & Bits, AppleSkin, FirstPerson, Physics Mod Pro, and VoiceChat. Resource packs add improved models, textures, and environmental effects, while shaders provide high-quality lighting and atmospherics.

You have a few setup options:

Full clone with LFS (recommended):

```
git lfs install
git clone https://github.com/Lonezsi/jraft_modpack
```

'Leave my configs alone' clone (mods + resourcepacks only, not recommended):

```
git lfs install
git clone --filter=blob:none --sparse https://github.com/Lonezsi/jraft_modpack
cd jraft_modpack
git sparse-checkout set mods resourcepacks
```

## TLauncher

For TLauncher, click the folder icon next to your instance to open the instance folder, then open a terminal or CMD in that folder and run the clone commands above. After cloning, your _mods_ and _resourcepacks_ folders will be ready, and you can launch the instance normally.

## Directory structure

```
📁 jraft_modpack/
 ├── 📁 mods/           # All Fabric mods used by the instance.
 ├── 📁 resourcepacks/  # Visual and audio modifications.
 ├── 📁 shaderpacks/    # Shaders loaded through Iris.
 ├── 📁 config/         # Configuration files generated by installed mods.
 └── 📄 options.txt     # Client settings, including resource pack load order.
```
